# Matrix Benzeri Will Akışı Plugini

## Seçenekler

### 1. Sohbet Akışı Göstergeleri
- **Lokasyon:** `conversation.input.dock` slotuna
- **İçerik:** Konuşma akışını görsel bir listede gösterir
- **Öğeler:** Mesajlar, araç çağrıları, model yanıtları

### 2. Session İstatistikleri
- **Lokasyon:** `conversation.input.dock` slotuna
- **İçerik:** Periyodik güncellenen istatistikler
- **Öğeler:** Token sayısı, mesaj sayısı, model kullanım istatistikleri

### 3. WebSocket Veri Akışı
- **Lokasyon:** `conversation.input.dock` slotuna
- **İçerik:** Harici kaynaklardan gelen gerçek zamanlı veriler
- **Özellik:** Belirtilen URL'den WebSocket ile veri çeker

Lütfen tercih ettiğiniz seçeneği /1, /2, /3 ya da özel bir açıklama ekleyerek belirtin.
