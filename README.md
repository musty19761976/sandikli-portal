# Sandıklı Tanıtım Portalı

Afyonkarahisar’ın Sandıklı ilçesini tanıtan modern, çok sayfalı statik web portalı.
Gerçek fotoğraflar Wikimedia Commons (Sandıklı + Akdağ) üzerinden sunulur.

## Nasıl açılır?

```powershell
cd C:\Users\musty\sandikli-portal
python -m http.server 8080
```

Tarayıcı: http://localhost:8080

veya `index.html` dosyasına çift tıklayın.

> Galeri ve arka plan görselleri internet üzerinden Wikimedia’ya bağlanır.

## Sayfalar

| Dosya | İçerik |
|--------|--------|
| `index.html` | Ana sayfa, istatistikler, foto şeridi |
| `tarih.html` | Kusura Höyük, zaman çizelgesi, efsaneler |
| `termal.html` | Hüdai Kaplıcaları rehberi |
| `kesfet.html` | Gezilecek yerler ve 2 günlük rota |
| `ekonomi.html` | Tarım, leblebi Cİ, sanayi, hayvancılık |
| `lezzet.html` | Gastronomi ve kültür |
| `galeri.html` | Gerçek fotoğraf galerisi + lightbox |
| `ulasim.html` | Ulaşım, konaklama, iletişim |
