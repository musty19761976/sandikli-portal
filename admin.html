Görsel Yönetim

Görselleri Cloudinary'e yükle, URL'leri al, Wikimedia bağımlılığını kaldır.

🔧 1. Cloudinary Bağlantısı

⚙️ Kurulum gerekli
  1. Cloudinary Console'de hesap aç
  2. Dashboard'dan Cloud Name'i kopyala
  3. Ayarlar → Upload → Upload presets → Unsigned preset oluştur
  4. Aşağıdaki alanları doldur → "Kaydet"e bas

📤 2. Görsel Yükle

Butona tıkla, dosya seç. Cloudinary'e yüklenir ve URL otomatik gösterilir.

🔗 3. Görsel Eşleme

Yüklediğin görselin public_id'sini site içinde kullanılan anahtarla eşle.

🔄 4. Wikimedia → Cloudinary Dönüştür

Eşleme yapılan tüm görselleri sayfada Wikimedia'dan Cloudinary'e çevirir.

Not: Bu sadece senin tarayıcında değişir. Kalıcı yapmak için HTML'i güncelle.
